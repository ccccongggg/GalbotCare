## 2. 任务目标（一句话）

> 一台能"**看着、记着、陪着、拦着**"的家用看护机器人：认得出老人、记得住老人讲过的往事、能陪做认知训练、能在老人跌倒或走失时第一时间通知家属，并把现场画面送到家属手机上。

场景叙事：《独居老人的一天》——08:30 认知训练 → 14:00 回忆录 → 15:20 跌倒告警 → 15:21 家属远程查看与点选导航。

## 3. 完成标准（现场可判定）

| 功能 | 完成标准 | 优先级 |
|---|---|---|
| FR-01 跌倒检测与告警 | 3 次跌倒演示 ≥2 次在 2.0s 内语音安抚；弯腰/坐下/蹲下对照动作误报 ≤1 次；手机端告警 ≤3s | P0 |
| FR-02 回忆录对话 | 3 分钟对话后自动生成 ≥1 条结构化回忆录；下轮对话正确回溯引用 ≥1 次 | P0 |
| FR-03 认知训练指物问答 | 连续 5 题指向命中 ≥4 题；判对错准确率 ≥80%；单题 ≤12s | P0 |
| FR-06 家属远程查看与点选导航 | 手机浏览器首帧 ≤5s；点击画面后机器人自主到位 ≤30s（5m 内） | P0 |
| FR-05 跟随防走失 | 5m 行走保持跟随 ≥90% 时间；越界 ≤2s 告警 | P1 |
| FR-04/07 抓取类（收拾/洗衣） | 能力延展展示，不进主线计时；失败即如实说明 | P2 |

> 范围声明：FR-07 洗衣明确不做开盖/设程序/投放洗涤剂（如演示，由人工完成并当场说明）。

## 4. 实现方式（分层架构 + 数据流）

```
L5 交互与呈现层   本地语音(TTS/ASR) + 家属网页端(视频流/告警/回忆录)
L4 Agent 规划层   任务仲裁器 TaskArbiter(P0-P4 优先级抢占) / 状态机 / 记忆库 / 事件日志   ← 自研核心
L3 技能层         SK-nav / SK-track / SK-point / SK-grasp / SK-speak / SK-look / SK-alert
L2 感知层         人体姿态检测、物体检测、跟踪（团队自建模型，跑自备电脑）
L1 机器人能力层   GalbotSDK：GalbotRobot / GalbotMotion / GalbotNavigation / GalbotPerception
```

- **L2/L4/L5 全部跑在团队自备笔记本**（局域网连机器人），机器人只负责取流与执行；天然支持离线回放验证，上机时段只做验证不做调试。
- **关键接口**：`get_rgb_data/get_depth_data/get_synced_observation`（取流）、`navigate_to_goal/stop_navigation/set_base_pose`（底盘）、`execute_joint_trajectory`（头部指向）、`set_gripper_command/get_gripper_state`（夹爪）、`set_leg_height`（升降 0.96–1.54m）。
- **已知约束**：G1 端侧感知仅立体深度、无目标检测 → 识别/跌倒判定全部自建；头部无深度相机 → 跌倒判定以像素+姿态判据为主、深度为副判据。
- **安全**：演示全程限速 ≤0.5（近人 0.3）；抢占顺序固定"停底盘→停臂→播报→推送"；全部技能带超时强制回 MONITOR。

## 6. 团队自主开发的内容（答辩"亮底牌"）

1. **任务仲裁与抢占调度器**（P0–P4 优先级、非阻塞调用 + 外部超时监控、断点降级）—— 完全自研。
2. **跌倒判定逻辑**：bbox 长宽比 / 头-髋高度占比 / 肩-髋水平角 / 深度一致性 / 时序滤波 + 静止二次确认的两级判定（疑似只出声，确认才告警）—— 判据与阈值为自研。
3. **认知训练指物链**：深度反投影 → 头部 2-DOF 指向 → 同义词表 + LLM 语义判等 —— 流程自研。
4. **家属远程端**：MJPEG 零转码转发、点选画面反投影导航（点选目标让机器人自己去，非摇杆遥控）、告警卡片与回忆录时间轴 —— 完全自研。
5. **动作编排与体态库**：12 原子动作模块 + 4 类对话体态（D-1~D-4）、四条任务链时间轴与交接约定 —— 自研。
6. **虚拟数字孪生演示环境**（`digital-twin/`）：Web 户型 + 虚拟老人动画状态机 + URDF 虚拟 G1 + Python 桥，用于离线验证动作链 —— 自研。

> 诚实声明：机器人底盘/导航/夹爪等底层能力来自官方 SDK 与出厂能力，不计为团队原创；演示中如出现遥控、人工辅助或预设动作，均已按官方要求如实说明（见 `05_合规与声明/人工接管记录表.md`）。
