# 测试与改进记录（ITER 表）

> 对应评分项"测试与改进 10 分"：根据尝试或反馈发现问题、采取针对性调整，用前后对比或运行记录说明变化。不以是否训练模型为加分前提。
> 官方要求演示中必须"简要说明一次改进及其结果" → **ITER-01 必须闭环一条**，且该条必须在 PPT 与讲词中出现。
> 铁律：所有数字来自真实日志/录屏；填不出来的格子宁可空着标注"待补测"，禁止编造。

---

## 记录规范（每条一个问题，七格一个不许省）

| 字段 | 填写要求 |
|---|---|
| 编号 | `ITER-XX`，按时间顺序递增 |
| 场景 | 哪个功能、第几次尝试 |
| 现象 | 客观描述 + 日志片段（贴原始文本）+ 截图/视频文件名（存 `06_素材库/`） |
| 根因 | 定位到具体代码行/参数/模型/场地因素 |
| 改动 | 改了什么：diff 摘要 / 参数前后值 |
| 复测 | 测试次数、通过次数、**关键指标前后值** |
| 结论 | 是否采纳、遗留问题、下一步 |
