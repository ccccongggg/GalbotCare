# T-16｜对话导演（话术状态机 + 音频通路）

> 优先级 P0｜工时 16 人时｜状态 未开始｜依赖：无（不需要机器人）
> 一句话：把"老人说什么 → 机器人说什么、什么时候说、说多少"做成一个可单测的模块，四条链共用。
> 为什么最先做：它不需要真机、不需要排队；认知链 70% 的"不像任务"的观感来自这里。

---

## 1. 交付物

1. `conversation/director.py`：状态机 + 事件驱动，纯 Python，无 SDK 依赖。
2. `conversation/lines.py`：台词常量表（与总则 §5 一致，全部 ≤15 字），**每行带 `posture` 字段**（`ANSWER` / `ASK` / `PRAISE` / `COMFORT` 四类之一）。
3. `conversation/guard.py`：LLM 输出护栏（字数/禁词/陈述提问比）。
4. `conversation/posture.py`：**体态映射**——把 `posture` 翻译成模块调用（D-1 只转头、D-2 转头+等待、D-3 点头+抬臂、D-4 侧头+掌心向上），动作实现见 `动作编排.md` §二。
5. `audio/tts.py`：文本 → 16k/16bit/mono PCM，落盘缓存 + 分块写出。
6. `audio/asr.py`：断句器（首字 3s / 说完 8s / 静音 1.2s）。
7. 单测：12 条对话路径 + 100 条话术合规样本 + **20 句体态映射抽检**。

> 说话时的肢体语言不在本模块里"发明"，只做"选类"：台词表标好类别，`posture.py` 按类调固定的一套动作。**同类永远同一套，不做变化**——这是你定的原则，也是省工时的关键。

## 2. 前置

- 一台笔记本 + 一个 TTS 服务（云端或本地）+ 一个 ASR 服务。
- 真机未到也可完成 100%；只有"写入扬声器"那一步需要机器人（留 `sink` 接口，先写 WAV）。

## 3. 子任务

- [ ] **3.1 状态机（4h）**
  - 状态：`CHAT`（闲聊）/ `PROPOSE`（提议）/ `ASK`（出题）/ `FEEDBACK`（反馈）/ `WRAP`（收场）
  - 事件：`老人开口` / `答案到达` / `检测到目标` / `情绪更新` / `抢占` / `静默超时`
  - **完成标志**：12 条路径（含"老人沉默""答错两次""被跌倒抢占"）全部单测通过，无死状态。

- [ ] **3.2 话术护栏（4h）**
  - 三条硬约束：≤15 字 / 命中禁词表即拦 / 每 3 句至少 1 句陈述。
  - 不合规 → 自动重写一次 → 仍不合规 → 退回模板句（`lines.py` 里取）。
  - **完成标志**：100 条生成样本，合规率 ≥98%，模板兜底触发率 ≤5%。

- [ ] **3.3 TTS 通路（2h）**
  - 统一转 16k / 16bit / mono；常用 20 句预合成落盘；冷启动直接读 PCM 分块写。
  - **完成标志**：缓存命中时首字出声 <300ms（用 WAV 打点计时）。

- [ ] **3.3b 体态映射（2h）**
  - 四类 `posture` 各绑一套固定动作：`ANSWER` 转头平视+双臂下垂；`ASK` 先转头看物+说完停 1s；`PRAISE` 点头 1 次+小臂轻抬；`COMFORT` 侧头+掌心向上小幅前伸。
  - 时序：头先 0.2s，手与语音同起，语音结束 0.3s 内回位。
  - **完成标志**：20 句台词抽检，体态与类别 20/20 对应，无一句"站着不动"或"乱动手"。

- [ ] **3.4 ASR 断句（2h）**
  - 3s 只等首字；开口后给 8s；1.2s 静音判句结束；超时返回空串而非报错。
  - **完成标志**：10 段老人慢速录音（含 3 段带长停顿），不被提前截断，误切 ≤1。

- [ ] **3.5 与链的接口（2h）**
  - 对外只暴露三个方法：`on_event(evt)`、`say(key)`、`next_action()`。
  - **完成标志**：T-03 / T-05 / T-06 三张卡各写一个 5 行的假调用能跑通。

## 4. 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 首字等待 | 3s | 超时算"不答"，不计错 |
| 说完窗口 | 8s | 老人语速慢，不能按 3s 截断 |
| 静音判句 | 1.2s | 短于 1.2s 的停顿不算说完 |
| 单句字数 | ≤15 | 收场句可到 18 |
| 预缓存句数 | 20 | 含跌倒 6 句、认知 8 句、通用 6 句 |

## 5. 验收

- 断网也能跑（TTS/ASR 有本地兜底）。
- 100 条话术样本合规率 ≥98%。
- 老人慢速说话不被截断（10 段录音误切 ≤1）。
- 单测 12 条路径全绿。

## 6. 降级

- LLM 不可用 → 全模板句（`lines.py`），对话变"薄"但不断。
- TTS 不可用 → 屏幕文字 + 机器人转头（T-05 已含）。

## 7. 不做

- 不做端到端情绪模型（只在 T-05 里用规则算两维分）。
- 不做多轮记忆（那是回忆录的事）。
