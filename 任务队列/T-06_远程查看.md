# T-06｜家属远程查看与点选导航

> 优先级 P0｜工时 17 人时｜状态 未开始｜依赖：共享取流、`get_transform`（或退化方案）
> 一句话：家属手机开网页就能看到第一视角画面，点画面里的位置，机器人自己走过去。
> 真机段：主线 3:50–4:30。**本链纯软件，可完全脱离机器人先用录制帧跑通。**

---

## 1. 交付物

1. `remote/server.py`：FastAPI，`/stream`（MJPEG）+ `/ws`（状态与指令）+ 口令鉴权。
2. `remote/web/index.html`：单页（视频 / 状态条 / 告警卡片 / 停止按钮）。
3. `remote/click_nav.py`：像素 → 深度 → 相机系 → 地图坐标 → `navigate_to_goal`。
4. 告警卡片数据接口（供 T-03 调用）。

## 2. 前置

- RGB 已是 JPEG 字节（`get_rgb_data`），**直接转发，不做转码**。
- 深度图 + 内参可用；`get_transform` 或退化链路（相机系 → 底盘系 → 里程计积分）。
- 局域网，手机与机器人在同一网段（**现场必须备本地热点**）。

## 3. 子任务

- [ ] **3.1 MJPEG 推流（4h）**
  - `/stream` 直接吐 JPEG 帧；断流自动重连；降级到 3fps 静帧刷新。
  - **完成标志**：手机浏览器首帧 ≤5s，端到端延迟 ≤1.5s（用秒表画面拍）。

- [ ] **3.2 点选反投影 + 导航（4h）**
  - 点击 → 该点深度 → 反投影 → TF → 地图点 → `navigate_to_goal(..., omni_plan=True, timeout=30)`。
  - 深度缺失（洞）→ 取该点 5×5 邻域中位深度，仍缺则提示"这儿看不清，换个地方点"。
  - **完成标志**：点 5 个位置，≥4 个到位，5m 内 ≤30s。

- [ ] **3.3 前端页面（6h）**
  - 视频区 + 状态条（电量/位置/当前链）+ 告警列表 + **显眼的"停止移动"按钮**。
  - 断连显示明确状态，不白屏。
  - **完成标志**：手机上一屏内看全，停止按钮一次点击即 `stop_navigation()`。

- [ ] **3.4 鉴权与接管礼仪（3h）**
  - 一次性口令进页面；进入前机器人必须播"小敏在看着您呢。"（**先告知老人，不许偷偷看**）。
  - **完成标志**：无口令进不去；播报在推流开始前完成。

## 4. 时序

| 时刻 | 动作 |
|---|---|
| 0s | 家属输口令 → 鉴权 |
| 0.3s | 机器人播"小敏在看着您呢。" |
| 1s | 推流开始，首帧 ≤5s |
| 持续 | `/ws` 下发状态；告警卡片推送 |
| 点击 | 反投影 → 导航（非阻塞 + 超时 30s） |
| 结束 | 家属点"结束" → 播"小敏不看了，我在这儿呢。" → 底盘退回原作业位 |

## 5. 验收

- 手机首帧 ≤5s；延迟 ≤1.5s；点选 5m 内 ≤30s 到位，零人工介入。
- 停止按钮生效 ≤0.5s。
- 机器人断连/WiFi 断 → 页面显示"机器人离线"，不白屏、不假流。

## 6. 降级

- WiFi 拥塞 → 机器人开热点保底；仍不行 → 降 3fps 静帧刷新。
- TF 不可用 → 相机系 → 底盘系 → 里程计积分（精度降到 ±0.3m，够用）。
- 点选不准 → 加"再点一次确认"（第一点只画标记，第二次才下发）。

## 7. 措辞红线（PPT 与答辩统一口径）

> **本功能为"家属点选目标，机器人自主导航"，不含连续摇杆遥控；若现场必须摇杆接管，如实计入人工接管次数。**

- 不写"遥控"，写"点选导航"。
- 不展示后台摇杆接口（即使有，也不上演示）。

## 8. 不做

- 不做多家属并发（一次一人）。
- 不做历史录像回看（只留告警截图）。
- 不做小程序/H5 分享（单页 HTML，零安装）。
