# T-07｜越界守护 + 跟随（拆两级）

> 优先级 P1｜工时 22 人时｜状态 未开始｜依赖：共享取流、定位/坐标换算、`navigate_to_goal`
> 一句话：老人走出安全区就播报+推送（**必做**）；若能上真机，再做 0.8–1.5m 跟走（**加演**）。
> 交付形态：加演 30s，或录屏。

---

## 1. 交付物

1. `chains/guard_chain.py`：守护（必做，不移动）。
2. `chains/follow_chain.py`：跟随（加演）。
3. `perception/track.py`：人体检测 + ByteTrack ID 稳定 + 深度反投影。
4. `nav/coords.py`：像素 → 相机系 → 底盘系 → 地图坐标（含退化链路）。
5. 安全区多边形配置文件（地图上一次标定）。

## 2. 前置

- 地图已建、`is_localized()` 为真。
- 单人跟走场景（多人 ID 跳变是最大风险源）。
- 限速 `set_navigation_velocity_limit([0.5,0.5,0.5])`，靠近人 ≤0.3。

## 3. 子任务

- [ ] **3.1 坐标换算（6h）**
  - 每 200ms：bbox → 深度 → 相机系 → `get_odom()` + TF → 地图点。
  - 无 TF 时用退化链路（误差 ±0.3m）。
  - **完成标志**：静止标定 5 个已知点，误差 <0.3m。

- [ ] **3.2 守护（4h）** ← **本轮必交，先完成这个**
  - 老人投影点落在安全区外 → 播报 + 推送（≤2s）；越界 60s 未回 → 通知家属。
  - 老人回区 → 静默，**不表扬不唠叨**（别把老人当小孩）。
  - **完成标志**：5m 直线走出边界，2s 内播报 + 推送成功。

- [ ] **3.3 跟随（8h）** ← 加演
  - 目标：老人后方 1.5m；>2.0m 前进；<1.2m `stop_navigation()`（**迟滞必须有**，否则走走停停像抽风）。
  - 全程 **M-14 双臂下垂**（不动手），头始终朝人（`精确`由 M-02 微调，幅度 ≤3°）。
  - `navigate_to_goal(..., omni_plan=True, is_blocking=False, timeout=5)`。
  - **完成标志**：5m 直线，跟随时间 ≥90%，距离始终 1.0–2.5m。

- [ ] **3.4 现场调参与素材（4h）**
  - 抓 3 段素材：正常跟随、绕桌重捕获、丢人后停住。
  - **完成标志**：3 段可用素材落盘（供 PPT/视频）。

## 4. 参数

| 参数 | 值 |
|---|---|
| 决策周期 | 200ms |
| 停距 | <1.2m（**不跟太近**） |
| 追距 | >2.0m |
| 目标点 | 老人后方 1.5m |
| 速度上限 | 0.5（贴近人 0.3） |
| 双臂 | M-14 下垂，全程不动 |
| 丢人判定 | 连续 5s 无目标 |
| 找人 | 停住 + 头左右各 30° 找 2 次 + 播报（**不做底盘原地扫描**） |

## 5. 收场

| 情形 | 处理 |
|---|---|
| 回到安全区 | "到家了，歇会儿吧。" → 交接闲聊 |
| 目标丢失 >5s | **绝不盲追**："您走慢点，我跟不上了。" → 停住 + 头左右各 30° 找 2 次 → 仍无 → 通知家属（**不动底盘**） |
| 卡住/被围 | `stop_navigation()` → 播报 → 请求人工（如实记接管次数） |

## 6. 验收

- 守护：越界 2s 内播报 + 推送，5 次 5 成功。
- 跟随（若上机）：5m ≥90% 跟随；距离不出 1.0–2.5m；全程双臂下垂不动。

## 7. 降级

- 真机时间不足 → **只交守护**（越界播报+推送），跟随用离线回放录屏，PPT 明确声明。
- 多人场景 ID 跳变 → 锁定"最近 3 秒内位移最小的 ID"，并用身高/衣着色直方图辅助。
- 地面打滑 → 限速降到 0.3，停距放宽到 1.0m。

## 8. 不做

- 不做出门禁/电子围栏硬件。
- 不做跨楼层跟随。
- 不承诺室外 GPS 找回。
