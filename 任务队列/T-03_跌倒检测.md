# T-03｜跌倒检测与告警

> 优先级 P0｜工时 18 人时｜状态 未开始｜依赖：T-16 音频通路、共享取流进程
> 一句话：老人在视野内倒地，**2 秒内出声、4.5 秒内到手机**，且不误报弯腰/坐下/蹲下。
> 真机段：主线 3:00–4:00。

---

## 1. 交付物

1. `perception/fall.py`：三级判定（SUSPECT / CONFIRMED / VISION_LOST）。
2. `chains/fall_chain.py`：两级发声 + 推送 + 撤警。
3. 6 句安抚语 PCM 缓存（`assets/fall/*.pcm`）。
4. 离线回放脚本：喂 RGB-D 序列重跑判定，输出召回/误报表。
5. `events.jsonl` 事件：`fall_suspect` / `fall_alert` / `false_positive` / `fall_cleared`。

## 2. 前置（不满足不开工）

- 共享取流进程可用（10Hz RGB+Depth 同步，`get_synced_observation`）。
- 人体姿态模型可推理（YOLOv8-pose，笔记本上 ≥15FPS）。
- 地面参考平面标定完成（一条命令算出地面深度常数）。
- T-16 的 `write_audio_stream_output` 通路可用（先写 WAV 也算）。

## 3. 子任务

- [ ] **3.1 判定模块（6h）**
  - 三判据：bbox 长宽比 ≥1.2 ／ 肩髋连线与水平夹角 <25° ／ 头部点低于髋部；连续 ≥15 帧。
  - 二次确认：SUSPECT 内位移 <0.15m 且持续 3s。
  - **完成标志**：离线 20 段真机视频，SUSPECT 召回 ≥90%，误报 ≤1/段。

- [ ] **3.2 两级发声状态机（4h）**
  - SUSPECT → **只出声不告警**："奶奶，您先别动。"（≤8 字，先给动作指令）
  - CONFIRMED → 推送 + "我这就告诉小敏。"
  - **完成标志**：软垫跌倒录像里，语音起播 ≤2.0s（用音轨打点比对）。

- [ ] **3.3 音频预缓存（3h）**
  - 6 句常安抚语预合成 16k/mono/16bit PCM，冷启动直接分块写。
  - **完成标志**：缓存命中首字出声 <300ms（现场合成会到 300–800ms，"2 秒"必超）。

- [ ] **3.4 推送（3h）**
  - 局域网 HTTP，载荷：时间 / 截图 / 置信度 / 位置。
  - **完成标志**：手机卡片可见 ≤4.5s（含判定 3.5s 后的推送 ≤0.4s）。

- [ ] **3.5 误报对照（2h）**
  - 弯腰捡物 ×3、坐下 ×3、蹲下 ×3，共 9 次。
  - **完成标志**：误报 ≤1 次，且每次误报都能在日志里追到是哪条判据放的行。

## 4. 参数表（初版，可调，调参记录进 ITER）

| 判据 | 阈值 | 备注 |
|---|---|---|
| bbox 长宽比 | w/h ≥ 1.2 | 主体判据 |
| 关键点水平度 | 肩-髋连线与水平夹角 <25° | 抗逆光 |
| 头部高度 | 头 y 低于髋 y 的占比 >0.7 | 与上一条取"或" |
| 深度一致性（**副判据，非必需**） | 人体区域中位深度 − 地面深度 <0.35m | **头部只有彩色相机、无深度**；深度只能来自手臂深度相机或 `FOUNDATION_STEREO` 立体。不可用时本条不做，只靠 2D |
| 时间持续性 | ≥15 帧（约 0.5s） | 抑单帧 |
| 静止确认 | 位移 <0.15m 且 3s | 区分"摔了"与"躺下" |
| 人体最小面积 | bbox 面积 ≥8% | 小于则判 VISION_LOST |

**动作时间轴（声先到、身再到，两条线并行）**

| 时刻 | 动作 | 台词 |
|---|---|---|
| 0.0s | **M-01** 停底盘 + 停臂 | — |
| 0.3s | — | "奶奶，您先别动。"（预缓存 PCM，2s 内出声） |
| 0.4s | **M-05** 原地转向老人 | — |
| 0.6s | **M-06** 靠近至 1.0–1.5m，速度 0.3 | — |
| 2.0s | 推送 + 告警卡片（与身体动作并行，不受靠近影响） | "我这就告诉小敏。" |
| 3.0s | 到位停稳 → **M-02** 头 pitch −15°（0.8s）→ **M-11** 启动降身（20cm，`duration=3`，非阻塞） | — |
| 4.4s | **M-13** 摆手 2 次（慢、小） + **M-04** 侧头 | "您怎么样？" |
| 6.2s | 降身到位（约 0.96–1.0m） | — |
| 6.5s | 保持 | "哪儿疼吗？能动吗？" |
| 7.0s | 保持，**不动手** | "要我扶您吗？" |

> 解释：评分要"2 秒内出声"，而"靠近—降身—摆手"到位要 6 秒。两者不矛盾——**先出声稳住老人，身体同时靠过去**；摆手不等降完（`set_leg_height` 一次就要 3–4 s），腿慢降、臂慢摆，**全项目只允许这一对并行**。

**分支动作**

| 情形 | 动作 |
|---|---|
| 家属接管 | **M-07** 后退 0.8m 让视线 + **M-14** 双臂下垂 → 切远程 |
| 老人说"没事" | **M-03** 点头 + "好，我在这儿，您慢点。" → **M-10** |
| 误报 | **M-04** 侧头 + "我眼花了，您别怪我。" → **M-10** |

## 5. 验收（现场可判）

- 软垫跌倒 3 次：语音 ≤2.0s 触发 ≥2 次，3 次推送全成功。
- 9 次对照动作：误报 ≤1。
- 相机被挡/画面全黑：进 `VISION_LOST`，播"我看不太清，您靠近一点"，**不告警**。

## 6. 降级

- 逆光/浅色地砖导深度跳变 → 砍掉"深度一致性"判据，只留框+关键点+时间（误报升到约 2/9）。
- 推送不通 → 本地语音循环播报 + 屏幕大字（也算送达）。
- 只来得及做一件事 → 先做"CONFIRMED 才告警"，SUSPECT 静默（丢掉 2 秒指标，但绝不误报）。

## 7. 不做（边界，答辩要讲）

- **不扶起、不搬动、不拉手臂**。医学上盲目搬动可加重骨折/颈椎损伤；工程上双臂无接触力控保障。
- 不做人脸识别、不做跌倒原因分析、不接医疗设备。
- 不承诺室外跌倒检出（只用头部相机视野内）。
