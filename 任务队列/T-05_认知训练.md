# T-05｜认知训练（指物识物问答）

> 优先级 P0｜工时 22 人时｜状态 未开始｜依赖：T-16（话术+音频+体态）、T-03（共享取流进程）
> 一句话：从闲聊里"长"出一道认物题，指给老人看，老人答，机器人判对错；全程不出现"训练/题目/得分"。
> 真机段：主线 0:25–1:30。

---

## 1. 交付物

1. `chains/cog_chain.py`：进入 → 出题 → 判等 → 反馈 → 延展 → 收场（6 槽位）。
2. `perception/objects.py`：3 类白名单检测（杯子 / 碗 / 遥控器）+ 深度反投影。
3. `skill/head_point.py`：头部 2 DOF 指向 + **指—拍—修**闭环。
4. `nlp/equiv.py`：同义词表 + LLM 语义判等。
5. `nlp/mood.py`：兴趣 I / 负荷 F 两维打分（阈值 0.6）。
6. `assets/cog/*.pcm`：8 句认知话术 PCM 缓存。

## 2. 前置

- 头部 head 组可用（2 DOF，非阻塞轨迹）。
- `get_camera_intrinsic` + `get_transform` 可用（反投影必需）。
- 3 类物体离线检测能跑（COCO 近类可先用，再补 20 张标注微调）。

## 3. 子任务

- [ ] **3.1 白名单检测 + 反投影（4h）**
  - 只检 3 类，深度 0.8–2.5m，取置信度最高且无遮挡者。
  - **完成标志**：离线 60 帧抽检，目标命中 ≥48 帧（80%）。

- [ ] **3.2 头部指向闭环（4h）**
  - 指 → 取一帧 → 找目标像素中心 → 修正 yaw/pitch 再指一次。
  - 开环必偏（头动了相机外参就变），这一步不能省。
  - **完成标志**：10 次指向，≥8 次落在画面中心 1/3。

- [ ] **3.2b 手臂指物姿态（3h）**
  - 末端是**夹爪**：不做"单指"。姿态＝一侧臂前伸（肩前屈 ~60°、肘近伸直）+ **夹爪闭合成薄片、薄片绕指向轴竖立、末端朝目标**，另一臂下垂（M-14）。
  - 手臂用预设关节角插值，不做 IK / motion_plan；方向偏差靠 3.2 的头部闭环 + 底盘微转补。
  - 时序：0.0 头先转到位 → 0.5 起手 → 1.3 停稳再开口 → 判等结束才收臂。
  - **完成标志**：指住 8s 内臂不漂；连做 10 次，老人（或队友）看第一眼能说出"它在指那个"。

- [ ] **3.3 判等（4h）**
  - 同义词表每类 ≥8 词（茶杯/缸子/水杯…）+ LLM 兜底；近似词算对，不纠正。
  - **完成标志**：60 条人工标注问答，准确率 ≥85%。

- [ ] **3.4 情绪两维（3h）**
  - I（兴趣）：回答字数 ≥8、主动反问、出现"我那时候…"、语速回升、笑声。
  - F（负荷）：连续 2 题未答、"记不住/老了/没用"、音量降 >6dB、停顿 >5s、叹气。
  - **完成标志**：20 段对话回放，与人工标注一致率 ≥70%。

- [ ] **3.5 串链联调（4h）**
  - 进入/主体/收场/交接四段连起来跑。
  - **完成标志**：连跑 5 题不卡，单题 ≤12s，收场句正确，交接后 5s 内有话。

## 4. T1 触发

| 通道 | 触发 | 用途 |
|---|---|---|
| A 家属下发 | 手机端"安排一场" → 日程队列到点主动发起 | **演示主用**，可复现 |
| B 老人主动 | 关键词："陪我聊会儿""认认东西""考考我" | 接评委即兴 |
| C 定时提议 | 节律窗口 + 5 道门控全过 | 真实居家 |

**C 通道五道门控（缺一不提议）**：① 人在视野 0.8–2.5m；② 姿态稳定 ≥10s；③ 当前无任务；④ 距上次 ≥3h 且今日 ≤2 次；⑤ 最近 30 分钟没被拒过。

> 第⑤条单独强调：**被拒一次，当天闭嘴**。第二次提议会让机器人被归为"烦人的东西"，后面所有链都被抵触。

**频率硬上限**：每日 1–2 次｜间隔 ≥3h｜单次 3–5 分钟（顶 6）｜单次 3–5 题（F 高时 2 题收）｜窗口 09:30–11:00、15:00–16:30，**避开 17:00 后**（认知症老人傍晚易激越）。

## 5. T2 进入：不宣布开始，题目藏第三句

| 模板 | 前提 | 三句 |
|---|---|---|
| A 借物 | 视野有白名单物体 + 老人正在闲聊 | ①"奶奶，您这杯子真好看。" ②"这杯子用不少年了吧？" ③（转头指）"您看，这个叫什么呀？" |
| B 借回忆 | 老人刚提到做饭/上班/带娃 | ①"您以前做饭最拿手的是啥？" ②"那盛菜的那个——" ③（指碗）"这个，您还认得吧？" |
| C 借关心 | 距上次喝水 >1h | ①"该喝口水啦。" ②"我给您倒？还是您自己来？" ③（指杯子）"您先说说，这叫什么？" |

**反例（禁用）**："我们现在开始认知训练，第一题……"——一句把陪伴变成任务。

**进入的隐藏条件**：老人正在讲往事（自述 ≥3 句）时**不要打断**，让回忆吃掉这段，训练顺延。打断一次表达欲的代价，远大于少做一次训练。

## 6. T3 单题 12 秒时序

| 时刻 | 做什么 | 说什么 |
|---|---|---|
| 0.0s | head 0.8–1.2s 平滑指向 | "您看那边——" |
| 1.2s | 停住不动（不要边指边晃） | "那个是什么呀？" |
| — | 等首字 3s；开口后给 8s；1.2s 静音判句 | — |
| 判等 1.2s | 同义词表 ∥ LLM，取先返回 | — |
| ≤3s | 四档反馈 | 见表 |
| 0–2 句 | 按需延展 | 见 §7 |

## 7. T4 四档反馈（永不判"错"）+ 兴趣延展

| 档 | 判定 | 台词 |
|---|---|---|
| 对 | 同义词命中 / 语义等义 | "对啦，就是杯子。您记性真好。" |
| 近似 | 上位词/方言/外形近（"茶缸"） | "差不多，咱们这儿叫水杯。"（**算对**） |
| 错 1 | 明确不同类 | 给语义提示："圆的，能装水，您天天用。" |
| 错 2 / 不答 | 再错 或 >3s 未开口 或"不知道" | "没事，这个是水杯，记住啦。" → **立刻接一个老人答得上的问题** |

**三条硬规则**：① 不说"错/不对/再想想"；② 不重复原句提问（换说法"再看看？"）；③ 答错后必须以一个"对"结束，不以"错"结束。

**I × F 决策表**

| I | F | 行为 |
|---|---|---|
| 高 | 低 | 加题（最多 +2）+ 延展 |
| 高 | 中 | 保持题量，切"您教教我" |
| 低 | 低 | 换物换话题，**不换形式**（别宣布换环节） |
| 低 | 高 | 立即收场，转安抚闲聊 |
| 任意 | F 高持续 2 题 | 立即收场，今天不再出题 |

**延展三路线（最多 2 条、加 ≤2 题）**：① 同类扩展"家里还有别的杯子吗？"；② 个人史"这杯子跟您多少年啦？谁买的？"；③ 让老人当老师"您教教我，怎么挑好杯子？"。

**跑题不要拉回**（从杯子讲到 1962 年）：那是回忆录的原料，用"后来呢？"接住。训练明天再做，往事今天不讲就忘了。

## 8. T5 收场（三要素：具体成果 + 不承诺下次 + 一个出口）

| 情形 | 台词 |
|---|---|
| A 正常 | "今天杯子、碗、遥控器，您都认出来了。" + "我陪您坐会儿，说说您年轻时的事？" |
| B 倦了（F 高） | "咱不认了，歇会儿。" + "我给您倒杯水？" |
| C 被打断 | 不补收场句，直接切；**30 分钟内不主动提"刚才没做完"** |

**禁说三句**："训练结束，您得了 X 分"／"明天我们再练一次好不好"／"您今天表现不太好哦"。

## 9. T6 交接

| 去哪 | 过渡句 | 配套动作 |
|---|---|---|
| 闲聊/回忆录（默认） | "您刚说那杯子跟您不少年了吧？" | 头部回正，平视老人 |
| 起身活动 | "坐久了，咱站起来走两步？" | 底盘后退 0.5m 让空间 |
| 家属端 | "小敏刚问您吃饭没有，我帮您回？" | 推送 |

判定标准：**交接句单独拿出来听不懂上文**，才算合格的过渡（因为它承接了上一件事）。

## 10. 验收

- 5 题：指向 ≥4 次落在中心 1/3；判等 ≥80%；单题 ≤12s；连跑不卡死。
- 全程无"训练/题目/得分/答错"字样（录音抓词自检）。
- 老人说"我不行"时，机器人下一句是"您慢慢来，我等着。"（抽测 5 次）。

## 11. 降级

- 物体检测不稳 → 只留杯子 + 碗（2 类，最好检）。
- LLM 不可用 → 只走同义词表（仍可跑，判等掉到 ~75%）。
- 情绪模型误判 → 只保留 F 的"不想答"布尔（连续 2 题未答即收场）。
- 头部指向超限 → 限幅 ±0.6rad + 半身微转补偿。

## 12. 不做

- 不做计分排名、不做题库扩充、不做多物体同屏出题（一题一物，视觉上才看得清）。
