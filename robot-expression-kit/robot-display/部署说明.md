# 机器人屏幕显示 · 队友部署包

G1 胸口竖屏（1080x1920）表情 + 跌倒警报红色感叹号显示程序。
原理：预渲染帧序列 + xcu `service_display` 高频推图（8fps）= 动画。

## 包内容

| 文件 | 说明 |
|---|---|
| `player.py` | 表情播放守护进程（xcu 运行，HTTP :8901 触发） |
| `alert_player.py` | 跌倒警报专用最小播放器（只循环播 alert 帧） |
| `orchestrator_lite.py` | 编排器·简化版：情绪→屏幕+颈部动作 |
| `orchestrator.py` | 编排器·完整版：+呼吸感/注意层/手臂/躯干/底盘/语音 |
| `render_frames.py` | 表情帧渲染器（开发机用，帧已预渲染） |
| `render_alert_frames.py` | 警报帧渲染器（开发机用，帧已预渲染） |
| `preview.html` / `alert_preview.html` | 浏览器预览页（无需机器人） |
| `alert_preview.gif` | 警报动画离线演示 |
| `frames_1080x1920/` | **竖屏帧序列（G1 官方屏竖装，主用）** 含 alert_loop 跌倒警报 |
| `frames_1920x1080/` `frames_portrait/` `frames/` | 其他朝向/小屏备用 |
| `DEPLOY.md` | 详细部署与对接文档 |
| `XCU_SERVICE_DISPLAY_手册.md` | service_display 手动推图速查 |

## 快速部署（xcu 上）

```bash
# 0. 整包拷到 xcu，如 /userdata/robot-display/
scp -r robot-display  root@<xcu>:/userdata/

# 1. 加载显示服务环境
source /data/config/default/service_display/profile

# 2. 启动表情播放器（在 service_display 所在目录执行）
cd <service_display 目录>
python3 /userdata/robot-display/player.py --bin ./service_display \
        --frames /userdata/robot-display/frames_1080x1920 --fps 8

# 3. 验证：切换表情 / 触发跌倒警报
curl http://127.0.0.1:8901/emotion -X POST -d '{"emotion":"happy"}'
curl http://127.0.0.1:8901/emotion -X POST -d '{"emotion":"alert"}'   # 红色感叹号
curl http://127.0.0.1:8901/emotion -X POST -d '{"emotion":"neutral"}' # 恢复

# 4. 测试结束恢复 WiFi 默认界面
systemctl restart launcher
```

跌倒检测程序只需在检测到跌倒时 POST `{"emotion":"alert"}`，解除后 POST `{"emotion":"neutral"}`。

## 只播警报（不跑表情系统）

```bash
python3 /userdata/robot-display/alert_player.py \
        --frames /userdata/robot-display/frames_1080x1920/alert_loop
# Ctrl+C 停止；systemctl restart launcher 恢复界面
```

## 常见问题

- 画面闪/卡：降 `--fps` 到 6 或 5（看播放器终端 30 秒一次的延迟统计）
- 命令无反应：确认先 `source` 了 profile，且当前目录能 `./service_display --help`
- 屏幕卡在测试图：`systemctl restart launcher`
- 想改警报文案：开发机 `python3 render_alert_frames.py --size 1080x1920 --out frames_1080x1920 --text "你的文案"`
